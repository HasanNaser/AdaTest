## التقنيات المستخدمة

- **HTML وCSS** لبناء واجهة عربية متجاوبة تدعم وضعَي النهار والليل وملء الشاشة.
- **JavaScript** لإدارة حركة الروبوت وتفاعله مع المؤشر وألعاب الحروف والكلمات.
- **Three.js وWebGL** لرسم الروبوت ثلاثي الأبعاد وتحريكه داخل المتصفح، مع الاستفادة من تسريع الرسوميات عند توفره.
- **Web Audio API وMediaRecorder** لتشغيل المقاطع الصوتية وتحليل شدّة الصوت وتسجيل المحاولات وإعادة سماعها.
- **Web Speech API** لتحويل الكلام إلى نص ومطابقة النتيجة مع الكلمة أو الحرف المطلوب. تعتمد الميزة على دعم المتصفح وإذن الميكروفون، وقد تحتاج إلى الإنترنت.
- **Local Storage** لحفظ إعدادات المظهر واختيار وضع النهار أو الليل على الجهاز.
- **GitHub Pages** لنشر المحاكي كموقع ثابت يعمل في المتصفح بدون خادم خاص أو قاعدة بيانات.
